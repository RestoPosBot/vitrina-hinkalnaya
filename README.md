# Витрина Хинкальной

Прототип витрины гостя: меню, карточка блюда, корзина, оформление заказа.
Телефон первым, устанавливается на домашний экран, меню работает без сети.

Меню настоящее — снимок боевой базы (`menyu.json`, 24 раздела, 350 блюд).
Заказ никуда не уходит: это демонстрация внешнего вида и удобства.

Фотографии в базе пока случайные — у хинкали макароны, у жареных шаурма.
Поэтому в шапке есть переключатель «без фото»: он показывает то же меню
прайс-листом, и это честнее, пока снимки не переснимут.
